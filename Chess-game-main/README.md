# ♟️ Angular Chess Game

An interactive, feature-rich 2D Chess application built with Angular and TypeScript. Includes active move highlights, check indicators, material advantage calculations, and pawn promotion.

---

## 🚀 Features

- **Interactive Chessboard:** Complete piece movement rules, turn-based highlights, and move indicators.
- **Visual Feedback:** 
  - Selected square highlighting.
  - Legal move dots and enemy capture ring indicators.
  - Red check highlight when a King is under attack.
- **Material Advantage Counter:** Real-time material score difference badges (+1, +3, etc.) for both players.
- **Pawn Promotion Modal:** Smooth pawn promotion selection dialog.
- **Responsive & Modern UI:** Dark slate UI with active turn indicators and status cards.

---

## 🛠️ Tech Stack

- **Framework:** Angular
- **Language:** TypeScript
- **Styling:** CSS3
- **Tooling:** Angular CLI, Node.js
